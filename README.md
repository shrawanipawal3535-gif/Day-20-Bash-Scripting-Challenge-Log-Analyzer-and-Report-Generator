# Day-20-Bash-Scripting-Challenge-Log-Analyzer-and-Report-Generator
Day 20 focuses on building a Log Analyzer and Report Generator using Bash scripting.
You create a script that reads a log file and analyzes it using commands like grep, awk, wc, sort, and uniq.
The script counts total lines, ERROR/WARNING/INFO messages, and finds top IP addresses.
It then generates a timestamped report file automatically.
This challenge improves text processing, scripting logic, and real-world log monitoring skills.
